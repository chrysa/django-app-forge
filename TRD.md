## Interfaces (FACT)

- **CLI:** `manage.py forgeapps [-c CONFIG] [--root R] [--base-path B]
  [--dry-run] [--force]`. Default config `apps.yaml`. Evidence: `forgeapps.py`,
  `README.md`.
- **Template variables:** `app_name` (snake), `app_label`, `app_class`
  (Pascal), `app_module` (dotted), plus any `context:` keys. Evidence:
  `README.md`, `naming.py`.
- **Errors surfaced as `CommandError`:** missing config, invalid YAML, invalid
  forge document. Evidence: `forgeapps.handle`.
