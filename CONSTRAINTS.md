# CONSTRAINTS — django-app-forge

> Each constraint tagged **[HARD]** (enforced/verifiable), **[SOFT]**
> (convention), or **[EXTERNAL]** (imposed from outside the repo).

## Build & install

- **[HARD]** Installation must fetch the private `chrysa-codegen` from
  `chrysa/chrysa-lib`; without a GitHub token the install fails. Evidence:
  `pyproject.toml`, `README.md`, `Dockerfile.test`.
- **[EXTERNAL]** `chrysa-codegen` is pinned by a specific commit SHA; upgrading
  the engine means bumping that pin. Evidence: `pyproject.toml`.
- **[HARD]** Python ≥ 3.14, Django ≥ 4.2. Evidence: `pyproject.toml`, `CLAUDE.md`.

## Runtime behaviour

- **[HARD]** Existing files are never clobbered unless `--force`. Evidence:
  `forgeapps.py`, `test_existing_file_is_skipped_without_force`.
- **[HARD]** `--dry-run` performs zero disk writes. Evidence:
  `test_dry_run_writes_nothing`.
- **[HARD]** An unresolved `{{ placeholder }}` aborts generation (never emitted
  literally). Evidence: `render.py`, `test_render_unknown_variable_raises`.
- **[HARD]** Generated output must remain byte-identical to the committed golden
  fixture. Evidence: `test_golden_output_is_byte_identical`.

## Architecture

- **[HARD]** Core modules (`spec`, `naming`, `render`, `generator`) stay
  import-free of Django; only `apps.py` and the management command touch Django.
  Evidence: `CLAUDE.md`, `AGENTS.md`, module source.
- **[SOFT/EXTERNAL]** chrysa canon: one class per file, named-argument calls,
  no hardcoded constants/secrets, typed errors, `pyproject.toml` as the single
  packaging source of truth. Evidence: `CLAUDE.md` managed standards block.

## Developer workflow

- **[HARD]** Tests, lint, typecheck, build run only through Docker or
  pre-commit — never directly on the host. Evidence: `Makefile`, `Dockerfile.test`,
  `CLAUDE.md`, `.claude/hookify.warn-host-test-lint.local.md`.
- **[HARD]** Coverage must stay ≥ 85%. Evidence: `pyproject.toml`.
- **[SOFT]** All committed content in English; this repo's generated
  `ai-instructions.md` guide is French by design. Evidence: `CONTRIBUTING.md`,
  hookify `warn-french-in-files`, `ai-instructions.md`.
- **[SOFT]** Conventional Commits; branch from `main` with typed prefixes;
  one PR per issue referencing a Shortcut story. Evidence: `CONTRIBUTING.md`,
  `CLAUDE.md` standards.

## Context files

- **[HARD]** `handover.md`, `ai-instructions.md`, `context-map.json`,
  `llms-full.txt` are generated by `scripts/gen_context_files.py` (ADR D-0012)
  and must be regenerated, not hand-edited. Evidence: file headers, `AGENTS.md`.
